# Результати опитування учасників липневих протестів 2026 року

Інтерактивний дашборд з результатами соціологічного опитування учасників
липневих протестів 2026 року.

## Перегляд

**https://kse-sociological-center.github.io/fedorov-protests-survey/**

Дашборд також можна відкрити локально — просто завантажте `index.html`
і відкрийте його у браузері. Файл повністю автономний: усі дані, стилі
та шрифти вбудовані всередину, інтернет для перегляду не потрібен.

## Розділи

1. **Соціально-демографічний профіль** — хто виходив на протест, порівняння
   з профілем населення України
2. **Участь у мітингах** — як і чому люди приходили
3. **Довіра** — довіра до політичних і військових постатей за шкалою 1–7
   та відкрите питання про найбільшу довіру
4. **Ліві-праві та авторитарні установки** — самопозиціювання на шкалі
   ліві–праві, пункти про авторитаризм і класифікація учасників
