# Результати опитування учасників липневих протестів 2026 року

Результати представлено в інтерактивному дашборді:

**https://kse-sociological-center.github.io/fedorov-protests-survey/**

Його також можна відкрити локально — просто завантажте `index.html`
і відкрийте його у браузері. Файл повністю автономний: усі дані, стилі
та шрифти вбудовані всередину, підключення до мережі інтернет для перегляду не потрібне.

## Структура дашборду

1. **Соціально-демографічний профіль** — хто виходив на протест, порівняння
   з профілем учасників липневих протестів 2025 року
2. **Участь у мітингах** — як і чому люди приходили
3. **Довіра** — довіра до політичних і військових постатей
4. **Ліві-праві та авторитарні установки** — самопозиціювання на шкалі
   ліві-праві, пункти про авторитарні установки і класифікація учасників
